# 麻雀AIを信じる前に【後編】構成案

作成・更新日：2026-09-26。本文執筆前の構成案。

## 最新の編集方針

ユーザーはNAGA批判の方針を撤回した。後編は、AIの推奨を絶対視せず、理解と学習につなげる方法を扱う。NAGAの公開段位戦データの追加公開を要求する章、実力の低さを印象付けるランキング、断罪的な見出しは構成から外した。

手出し・ツモ切りの現行仕様は引き続き未確認として扱う。

## タイトル

第一候補：**AIの一打は「神の一手」なのか？**

別案：**AIの一打を、どう学ぶ？――強さと理解のあいだ**

シリーズ表記：麻雀AIを信じる前に【後編】

## 記事の軸

前編では、期待値を計算するモデルの前提を確認した。後編では、AIが何を学び、どんな目標で行動を選び、人間がその判断をどう学べるかを考える。

中心となる主張：**AIの推奨を受け取り、理由を検討し、自分の判断に生かす。**

AIの対局の強さ、各局面の最適性の証明、人間への説明能力を分ける。どれか一つが優れていても、他の二つが自動的に保証されるわけではない。

想定分量：4,500〜6,000字程度。学習方法の図と、推奨から理解へ進む図を基本とする。

## 1．AIと意見が違ったとき、何を学べるか

- AIを使うことで、自分が気付かなかった選択肢に出会える。
- 前編の「どんな前提で計算した期待値か」を、「何を学んだAIの、どんな目的の推奨か」へつなげる。
- AIと違うことだけで自分の打牌を否定せず、その違いを検討の入口にする。
- 導入候補：「AIの推奨と違う牌を切った。そのとき、間違えたと思う前に、なぜ判断が分かれたのかを考えてみたい。」

## 2．NAGAは、人間の強者の判断から学んだAI

- 公開説明では、天鳳の高段位者・鳳凰卓の牌譜から打牌などを学習している。
- 局面の情報を入力し、打牌の分布を予測する仕組みを説明する。
- 人間の強者の打ち方を整理し、自分の判断との違いを調べる用途につなげる。
- 言い方は「その局面で人間の強者が選びそうな行動を学習・推定する」。同一局面の投票を数えて決める単純な多数決とは説明しない。
- 学習した特徴を未見の局面にも適用するため、「記録にない一打は選べない」とは書かない。
- 「人間が理解しやすいか」は学習方法だけでは保証されない。NAGAの推奨でも理由を検討する。
- 現行すべての版の詳細な学習工程は未確認。公開説明上の基本として教師あり学習を紹介する。
- NAGA公式が推奨を一人の強者の意見として見るよう説明している点も紹介する。
- 出典：[2019年の開発者解説](https://dmv.nico/ja/articles/mahjong_ai_naga/)、[2025年のドワンゴ説明](https://dwango.co.jp/news/6454281032957952/)、[NAGA公式の推奨の読み方](https://note.com/naga_project/n/n61a012f27261)。

## 3．人間の常識に縛られず、戦略を学ぶAI

- 強化学習は、行動後の報酬をもとに方策や価値を改善する方法。教師あり学習と組み合わせることもある。
- 将棋AIの具体例にはAlphaZeroを使う。将棋AI全体が同じ学習方式とは書かない。
- AlphaZeroは自己対局の強化学習と探索を使い、将棋・囲碁・チェスで高い対局性能を示した。
- 羽生善治氏が、人間の将棋理論から見ると危険に見える手でも局面を制御していたと述べた例を要約する。
- 人間の直感からは理由を説明しづらい選択が現れることがある。ただし頻度を測っていないので「ほとんどの手が理解不能」などとは書かない。
- 「強化学習」は学習方法であり、すべての強化学習AIが毎打牌で大量の未来を探索する意味ではない。
- 図案：人間の牌譜から学ぶ経路と、自己対局・報酬から学ぶ経路。優劣の上下配置にはしない。
- 出典：[DeepMindのAlphaZero解説](https://deepmind.google/blog/alphazero-shedding-new-light-on-chess-shogi-and-go/)、[原論文](https://storage.googleapis.com/deepmind-media/DeepMind.com/Blog/alphazero-shedding-new-light-on-chess-shogi-and-go/alphazero_preprint.pdf)。

## 4．LuckyJと「神の一手」への期待

- LuckyJは、強化学習と後悔最小化を組み合わせた自己対局学習に、不完全情報下の探索を加える仕組みと開発側が説明している。
- 天鳳特上卓の安定段位10.68という2023年の公表実績を紹介し、高い対局性能を示す一つの事例として位置付ける。
- 人間の常識に合わせることを学習目標としない方法から、従来の定石とは違う戦略が見つかる可能性を説明する。
- LuckyJの意外な一打を載せる場合は、実牌譜を特定し、局面・候補手・点況・その後の選択を確認する。意外さの頻度や優位性を印象だけで断定しない。
- 『ヒカルの碁』の「神の一手」を、人間の常識を超える発見への期待を表す比喩として使う。
- 論点は「人間がよく選ぶ手」と「特定条件で有利な手」が一致しない可能性。教師ありAIにも学習の一般化があるので、「NAGAは神の一手を絶対に選べない」とは書かない。
- LuckyJの強い成績は、すべての局面の打牌が数学的に最適だという証明ではない。麻雀では相手の戦略、見えない牌についての想定、点数や順位の目標によって判断が変わる。
- 出典：[Tencent公式発表の許諾訳](https://modern-jan.com/blog/luckyj_article_ja/)、[担当研究者の公開ページ](https://haobofu.github.io/)。
- Tencentの中国語原文は今回の取得で開けず、技術説明には許諾訳を用いたことを記録する。

## 5．強い手を選べることと、理由を説明できること

- AIがどの行動を選ぶか、どの程度対局で強いか、その判断を人間が理解できるかを分けて考える。
- 人間があとから筋の通る解説を付けても、それがモデルの実際の判断根拠を忠実に説明したとは限らない。
- 自然な文章の説明と、比較条件を固定した検証は役割が違う。
- 説明可能性の研究は進んでいる。AlphaZeroから新しいチェスの概念を抽出し、トップ棋士への学習・移転を調べた研究もある。
- この研究を、LuckyJの全打牌の理由を言語化する機能の証明には使わない。
- 「AI研究は言語化まで進んでいない」と一括りには書かない。麻雀AIの各推奨を十分に説明・検証する難しさを論点とする。
- 図案：推奨を得る → 理由の仮説を作る → 条件を変えて比較する → 自分の判断に生かす。
- 出典：[AlphaZeroの知識抽出・人間への移転研究](https://arxiv.org/abs/2310.16410)、[NAGAの特徴の可視化に関する開発者説明](https://dmv.nico/ja/articles/mahjong_ai_naga/)。

## 6．牌譜検討で、AIの数字をどう読むか

- 推奨度・一致率・類似度・価値の推定値が、それぞれ何を表すかを確認する。
- NAGAの複数タイプで推奨が分かれることを、多様な戦略を考える材料として紹介する。不一致率を誤り率とは扱わない。
- ユーザー提供の2024-10-03付サポート回答は、指標の対象範囲を確認する例として短く要約する。打牌選択が対象で、副露・立直・槓の判断は対象外という当時の説明を示す。
- 数値を改善することと、実戦で判断を改善することの関係を考える。
- ルール・点況・モデル・バージョンを確認し、その後の手牌進行も合わせて検討する。
- 学習方式の補足表を置く場合、Mortalは深層強化学習、MAKAの方式は未確認とする。
- 出典：[NAGA公式の指標の説明](https://note.com/naga_project/n/n61a012f27261)、[MortalレビューFAQ](https://github.com/Equim-chan/mjai-reviewer/blob/master/faq.md)、ユーザー提供の2024年サポート回答。

### 小欄：手出し・ツモ切りの仕様は確認中

現行NAGAが他家の手出し・ツモ切り情報を打牌判断にどう利用するかは、現時点では確認できていない。入力の区別、予測表示への影響、最終的な打牌判断での利用を分ける。回答がなくても本文を完成できる構成とする。

## 7．AIから学び、自分の判断を育てる

- 自分にない選択肢を知り、推奨の理由を仮説として考える。
- 理解できない手は、理由が分からないまま正解や悪手と決め付けず、局面の条件とその後の選択を調べる。
- 各AIの強さや特徴を尊重し、日々の検討に使う。
- 結び候補：「AIの一打を見たら、そこから自分の麻雀を考える。その積み重ねが、AIを使って学ぶということなのだと思う。」
