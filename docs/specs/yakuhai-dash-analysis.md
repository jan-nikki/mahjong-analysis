# 役牌ダッシュ分析仕様

## 目的

配牌から孤立役牌を早く切る戦術を「役牌ダッシュ」と呼び、次の二つを同時に
記述する。

1. 役牌を保持したとき、自分が2枚目を自摸して対子になる機会。
2. 役牌を切る時点までに、他家が同じ牌を2枚以上持ちポン可能になる危険。

初版はこの二つの機構と実際の採用率を分析する。役牌ダッシュ群と保持群の
和了率・放銃率の単純比較は、配牌の手牌価値、混一色適性、向聴数などによる
交絡が大きいため行わず、戦術の因果的な局収支優位を直接示すものとはしない。

## 対象

- 四人麻雀の鳳凰卓東南戦、赤あり（MJAIファイル名のrule code `00a9`）
- 2020年から2025年
- 東場のみ
- 配牌は`start_kyoku.tehais`の各13枚とする
- 親の第1自摸は配牌に含めず、自摸1回目として扱う

## 役牌

各actorについて、三元牌、場風、自風を役牌とする。同一牌種は重複させない。
東場では親が4種類、子が5種類を持つ。

牌種を次の排他的区分に分ける。

- `dealer_double_wind`: 親にとっての東
- `shared_round_wind`: 子にとっての東
- `shared_dragon`: 白・發・中
- `own_seat_wind`: 子にとっての南・西・北のうち自風

最初の3区分は他家にとっても役牌になり得る共有役牌、`own_seat_wind`は
原則として他家には役牌にならない自家専用役牌としても集約する。

## 配牌集計

局・actorを1観測として、各役牌牌種の配牌枚数0〜4を数える。最低限、全体、
親、子について次を保存する。

- actor配牌数
- 役牌牌種機会数
- 牌種単位の配牌枚数分布
- 役牌対子以上を1種類以上持つactor数と率
- actor内の役牌対子以上の種類数分布
- actor内の孤立役牌種類数分布

「対子以上」は同一牌種を2〜4枚持つ場合とする。東を親について2種類に
重複計上しない。

## 役牌ダッシュ

配牌にちょうど1枚あった役牌を、同牌の2枚目を得る前に孤立のまま切った
場合を`singleton_discard`とする。actorの打牌番号は鳴き後の打牌を含め、
本人の`dahai`だけを1から数える。

- 主定義 `strict_dash`: 第1打が配牌孤立役牌の`singleton_discard`
- 補助定義 `dash_by_2`: 第2打までに1種類以上を`singleton_discard`
- 補助定義 `dash_by_3`: 第3打までに1種類以上を`singleton_discard`

自摸で対子になった後に1枚を切る対子ほぐしは、役牌ダッシュに含めない。
配牌孤立役牌を1種類以上持つactor配牌を手牌単位の正式分母とする。牌種単位の
切り巡目分布も別に保存する。

手牌構成による採用差の診断として、配牌の最多色枚数、字牌枚数、全対子牌種数、
向聴数、ドラ翻数でも手牌単位の採用率を保存する。向聴数は配牌13枚の通常形、
七対子、国士無双の最小値とする。ドラ翻数は局開始時の表ドラ表示牌から
求めるドラ枚数に赤5枚数を加え、赤5が表ドラでもある場合は2翻と数える。
また本人の第1打までに他家が何打したかを記録し、その回数でも層別する。
これらは手牌価値を完全に調整するものではない。

第1打が発生しない局も配牌を分母とする採用率には含む。第1打が発生した
配牌だけを分母とする`strict_dash_given_first_discard`も併記し、局終了で
行動機会のなかった配牌との違いを明確にする。

## 配牌孤立役牌の追跡

局・actor・役牌牌種を1観測とする。配牌枚数がちょうど1枚の牌種だけを追跡し、
最初に起きた次の排他的結果を保存する。

- `self_pair_draw`: 保持中に本人が同牌を自摸し、対子以上になった
- `singleton_discard`: 対子になる前に本人が孤立のまま切った
- `round_end`: どちらも起きずに局が終了した

`self_pair_draw`では本人の何回目の自摸かを保存し、exact回数と累積率を出す。
`singleton_discard`では本人の何打目か、打牌直前に同牌を2枚以上持つ他家が
存在したか、その人数、実際にポンされたかを保存する。

本人が対子になった後、他家の打牌を実際にポンしたかも補助指標として保存する。

schema version 3では、対子化後の最初の本人の打牌について、打牌直後に
対象牌が純手牌に2枚以上残っているかを`self_pair_retained_after_discard`、
さらに本人がリーチ宣言・成立のいずれもしていないかを
`self_pair_pon_shape_after_discard`として保存する。リーチ宣言牌を打った時点でも
後者はfalseとし、成立イベントを待たない。該当打牌のイベント番号と原本行番号も残す。

2枚目を引いて直ちに1枚切った場合は`self_pair_draw`には数えるが、保持指標は
falseとなる。その後に再度対子化しても、最初の打牌の判定は変更しない。
自摸和了・局終了等で後続の本人打牌がない場合は、両指標と当該打牌のイベント番号をnullにする。
間に槓が入った場合は嶺上牌も処理した後の最初の本人打牌で判定する。

集計`self_pair_followup`では、ポン可能形、対子非保持、対子保持だがリーチ制約あり、
後続本人打牌なしの4区分が`self_pair_draw`件数に一致する。対子保持件数は
ポン可能形とリーチ制約ありの和として併記する。これらの全体率の分母は
`self_pair_draw`件数とし、元の対子化自摸回数ごとの件数・累積率は
全配牌孤立役牌観測数を分母とする。横軸は対子化した自摸回数であり、
槓の嶺上自摸を挟む場合の「保持を確認した自摸回数」とは一致しない。

これは打牌直後の手牌形とリーチ状態の指標である。残り牌の所在、その打牌による
局終了、次の他家打牌の有無等は条件に含めず、実際のポン機会数や完全な合法行動判定
としては解釈しない。実ポン件数とは別に扱う。

孤立役牌を切った後も局末までイベントを読み、同牌を後から本人が自摸した
最初の時点と、他家が同牌を新たに対子化した最初の時点を別系列に保存する。
これは実際に打った結果の牌譜上の経過であり、「切らずに保持していた場合」の
反実仮想とは解釈しない。切った結果で鳴きや自摸順が変わり得るためである。

## 他家の対子化

配牌孤立役牌ごとに、次を完全情報から求める。

- 配牌時点で同牌を2枚以上持つ他家がいたか
- 本人が`self_pair_draw`または`singleton_discard`に至る前に、他家が自摸で
  初めて2枚以上になったか
- その時点までに本人が完了していた自摸回数

この情報は牌譜に含まれる全員の手牌を使う研究用の完全情報であり、対局者が
知り得た情報ではない。本人側の結果確定後に起きた他家の対子化は数えない。

打牌直前の`opponent_pon_capable`は、その時点の他家純手牌に同牌が2枚以上
あり、かつその相手が成立リーチ後でないこととする。枚数だけの保有者数も
別に保存し、リーチ中の保有者だけが存在した打牌を区別する。鳴く意思、
他の局面上の鳴き制約、役の有無、点棒状況は条件にしないため、これは
リーチ状態を考慮したポン可能形の指標であり、完全な合法行動判定ではない。
実ポン率とは別に保存する。

「どちらが先に対子化したか」は配牌時他家対子、自分が先、他家が先、
どちらも対子化する前に本人が孤立牌を切った、どちらも対子化しないまま
局終了の排他的5区分とする。各区分を本人側の3結果とも交差集計する。

本人の第1打直前に対象牌が表に見えていた枚数も記録する。局開始時と
追加のドラ表示牌、河、公開された副露牌を含める。自家第1打が発生しない
場合はnullとして、観測数を別に示す。

## 理論基準

実装検証と解釈用に、136枚から無作為に13枚を取る組合せ論上の基準値を
出力へ保存する。

- 特定牌種が対子以上になる確率
- 4種類または5種類の役牌のうち1種類以上が対子以上になる確率
- 特定役牌を配牌で1枚持つとき、自分の第1〜18自摸までに残り3枚のうち
  1枚以上を引く累積確率

最後の値は未知の123枚から自分の自摸位置を無作為抽出する単純モデル
`1 - C(120, n) / C(123, n)`である。見えている牌、他家の手牌、鳴きによる
自摸順変化、局終了は反映せず、実牌譜の観測率とは区別する。

## 集計

全体、年度別について、配牌、手牌単位ダッシュ、配牌孤立役牌を集計する。
配牌孤立役牌はさらに次で分ける。

- 親／子
- 共有役牌／自家専用役牌
- 4つの役牌区分
- 実牌種（E/S/W/N/P/F/C）

率は整数countから計算し、分母0は`null`とする。年度合算は年度率の平均ではなく
countを合算して再計算する。

## 出力と実行

全件既定出力は`outputs/yakuhai-dash/summary-v3.json`とする。
`--max-logs-per-year N`を指定したサンプル実行は
`summary-v3-sample-N.json`へ出す。既存のv2全件出力は新指標を含まない。
既存出力を上書きせず、完成したJSONだけを
排他的に公開する。年度は独立workerで処理でき、serial/parallelで同一結果にする。

`--progress`は各年の開始・途中・完了時に、走査済み/総牌譜数、対象牌譜数、
東場局数をstderrへ即時出力する。途中表示は牌譜単位の処理が終わった時点で
件数または時間の間隔に応じて行う。
`--checkpoint-dir DIR`を指定すると、完了した年から`year-YYYY-v3.json`を
保存する。他年の失敗時も完了年の出力は残る。これは途中成果の保存であり、
自動再開・既存ファイル再利用の機能ではない。既存の同名ファイルがある場合は
走査前にエラーにする。

元MJAIへ戻れるよう、配牌対子と非対子、strict dashと第1打非dash・第1打なし、
自摸対子化と非対子化、配牌時他家対子と非対子、打牌時ポン可能と非可能、
リーチにより鳴けない対子保有者、実ポン、打牌後の同牌自摸と他家対子化、
自家専用役牌から決定論的な先頭標本を年度ごとに保存する。
v3では対子化後のポン可能形あり・なし（後続打牌なしを含む）も加え、計19区分とする。
各年の区分別母集団件数と設定標本上限を記録する。

監査は対象年・区分の欠落や重複、必須フィールド欠落、同一区分内の標本重複、
空の検査集合を不合格にする。v3では母集団件数を年度集計と照合したうえで、
各区分の標本数が`min(母集団件数, 設定上限)`に一致することを要求する。
母集団が0件の区分は標本0件を許す。標本保存を無効にした出力は保存標本監査に
合格できない。v2も明示的に入力できるが、旧出力は設定上限を含まないため、
厳密な上限照合は行わず、母集団がある区分の標本欠落を検出する。
別選定監査でも、年ごとに対象牌譜・東場局の検査実績が0件なら不合格にする。

## 必須不変条件と検証

- 全actor配牌数は東場局数の4倍
- 親配牌数と子配牌数の和が全actor配牌数
- 配牌枚数分布の合計が役牌牌種機会数
- 配牌孤立役牌の3結果の合計が全孤立役牌観測数
- 自摸回数分布の合計が`self_pair_draw`
- 対子化後の4区分の合計が`self_pair_draw`、保持件数がポン可能形とリーチ制約の和
- 孤立打牌回数分布の合計が`singleton_discard`
- 実ポン数は打牌時ポン可能数以下
- 先着5区分と本人結果3区分の交差表はそれぞれ孤立牌観測数へ合計一致
- 打牌後の同牌自摸・他家対子化件数は孤立打牌件数以下
- 手牌条件別と第1打前の場情報別の分母は対象集団に一致
- 年度merge、serial/parallelで内容と順序が一致
- 親子の役牌種類、自風、配牌対子、配牌時他家対子、本人自摸での対子化、
  他家自摸での対子化、孤立第1〜3打、対子ほぐし除外、ポン可能だが見送り、
  実ポン、リーチ済み対子保有者の除外、早切り後の本人同牌自摸と他家対子化、
  第2・第3打、鳴き・槓による手牌更新を人工MJAIで検証する
- 理論確率を独立した組合せ式の期待値で固定する

本番実行後は監査標本の`start_kyoku`、対象actor、対象牌、関連`tsumo`、
`dahai`、`pon`をMJAI原本で目視確認する。
