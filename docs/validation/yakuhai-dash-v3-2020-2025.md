# 役牌ダッシュ分析 v3・2020〜2025年全件実行と原本監査

実施日: 2026-09-25
対象: 四人麻雀・鳳凰卓東南戦の東場、MJAI原本
全件出力: `outputs/yakuhai-dash/summary-v3.json`
総括監査: `outputs/yakuhai-dash/audit-v3.json`

## 結論

6年分の全件実行は正常終了した。保存標本と別選定牌譜の原本照合は不一致0件で、
新指標を除く従来の全体・年別集計はv2全件結果と完全一致した。
これは標本監査の合格であり、全対象牌譜の全イベントを独立実装で再集計したことや、
役牌ダッシュの局収支・和了率上の優位性を実証したことを意味しない。

## 入力と主要結果

- 1,105,845ファイルを走査し、対象は1,105,844牌譜。対象外1件は2025年のrule code `00e1`。
- 東場6,374,545局、actor配牌25,498,180件、配牌孤立役牌34,948,620観測。
- 配牌で役牌対子以上は5,165,483/25,498,180配牌（20.258%）。
- 配牌孤立役牌を持つ対象配牌で、初打にその役牌を切る厳密ダッシュは
  5,082,943/20,619,520配牌（24.651%）。
- 孤立役牌を保持中に本人が2枚目を自摸したのは
  3,355,487/34,948,620観測（9.601%）。本人1回目の自摸までに2.427%、
  3回目までに累積5.936%。横軸は局全体の巡目ではなく本人自摸回数である。

2枚目を自摸した3,355,487件について、その後の最初の本人打牌直後を分類した。

| 状態 | 件数 | 対子化例に対する割合 |
| --- | ---: | ---: |
| 対子保持・リーチ制約なし（ポン可能形） | 3,238,720 | 96.520% |
| 対子を崩した | 78,924 | 2.352% |
| 対子保持・リーチ制約あり | 24,773 | 0.738% |
| 後続の本人打牌なし | 13,070 | 0.390% |

4区分の合計は対子化件数と一致する。対子保持は上表の第1・第3区分を合わせた
3,263,493件（97.258%）。「ポン可能形」は打牌直後の手牌枚数とリーチ状態の指標で、
実際のポン機会や完全な合法行動判定ではない。本人が対子化後に実際にポンした件数は
1,098,895件（対子化例の32.749%）であり、別指標として扱う。

## 監査

`analysis/audit_yakuhai_dash.py`の原本再構成部分は本分析のMJAIローダや判定関数を
使わず、開始配牌とイベント時系列を別経路で求める。別選定監査では本番判定関数の
結果とその独立再構成を照合する。配牌向聴数も手牌全体DFSで独立計算する。
総括監査と各年の先行監査はすべて合格した。

| 検査 | 規模 | 結果 |
| --- | ---: | --- |
| 年別・判定別に保存した標本 | 6年×19区分×3件＝342件、62原本、重複除去後223観測 | 不一致0 |
| 全期間に広げた別選定 | 各年24牌譜、計144牌譜・東場845局・配牌3,380件・孤立役牌4,603観測 | 不一致0 |
| v2との既存集計照合 | 入力件数、全体・年別の新指標以外の全集計 | 完全一致 |
| 新指標の不変条件 | 4区分の合計、保持内訳、年度合算、配牌数＝東場局数×4 | 一致 |
| pytest全体 | 1,516件 | 通過 |

別選定は対象rule codeのファイル名を各年の先頭から末尾まで均等に選ぶ決定論的標本で、
無作為抽出ではない。選定した東場局では原本配牌から孤立役牌を全列挙し、
判定の取りこぼしと余計な検出の双方を照合した。

全件出力の保存標本に含まれる以下の3例は、展開後MJAIの原本行を個別にも確認した。

- 2020年 `2020010100gm-00a9-0000-03aa14b0.mjson`、開始342行、actor 1、東:
  351行で2枚目の東を自摸し、352行で九萬を切る。東対子を保持し、ポン可能形はtrue。
- 2020年 `2020010100gm-00a9-0000-bd4f68bf.mjson`、開始255行、actor 2、中:
  304行で中を自摸し、305行で中を自摸切り。対子化自摸には数えるが保持はfalse。
- 2025年 `2025010100gm-00a9-0000-b13f707c.mjson`、開始2行、actor 2、東:
  91行で東を自摸し、92行で自摸和了。後続の本人打牌がないため保持判定はnull。

## 再現と限界

```powershell
.venv\Scripts\python.exe analysis\analyze_yakuhai_dash.py --workers 6 --progress --checkpoint-dir outputs\yakuhai-dash\v3-full-years
.venv\Scripts\python.exe analysis\audit_yakuhai_dash.py --input outputs\yakuhai-dash\summary-v3.json --compare-v2 outputs\yakuhai-dash\summary-v2.json
.venv\Scripts\python.exe -m pytest -q
```

同じ全件出力・年別保存先が存在する状態で集計コマンドを再実行すると安全のため停止する。
再集計には未使用の`--output`と`--checkpoint-dir`を指定する。監査コマンドは既存結果を
読み取るだけなので再実行できる。

標本監査で不一致0は未抽出局の誤り0を保証しない。役牌を切った後の自摸・他家対子化は
実牌譜上の経過であり、保持していた場合の反実仮想ではない。局収支、和了率、放銃率、
手牌価値を比較していないため、この記事段階で「役牌ダッシュが有利」とは結論しない。
今回の総括監査を実行したモデルと推論強度は確認できず、`AGENTS.md`指定の
`Astra / xhigh`で実施したとは表記しない。モデル指定への適合は未確認である。
