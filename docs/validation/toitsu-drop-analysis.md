# 対子落としに見える河の後のリーチ：検証記録

## 対象

`data/processed/riichi-waits-v1` の2009～2025年、鳳凰卓東南戦・赤あり・東場の
成立リーチ10,706,714件を対象にした。観測単位は成立リーチ1件である。

主条件は、本人の連続する2打が同じ正規化牌種で、2枚目が手出しであることとした。
1枚目が手出しならA、ツモ切りならBとし、河の外形を分類する。これは実際に手牌内の
対子を意図して落としたことを証明するものではない。

## 実行結果

2026-09-21に次を実行した。

```powershell
.\.venv\Scripts\python.exe .\analysis\analyze_toitsu_drop.py --workers 4
```

- elapsed: 524.5秒
- output: `research/results/toitsu-drop-analysis-v1.json`
- output size: 6,203,860 bytes
- output SHA256: `24f0705ecd8a0dc9066198c3feb6cb14a82db5532f296c081ef59cbd7bfa7c63`

入力manifest、17年分のannual gzipのsize/SHA256、DTO、年次行数、総行数を検証しながら
streaming集計した。総行数はcanonical manifestの10,706,714件と一致した。分割前の
全レコード集計は既存の`riichi-wait-quality-v1.json`と全期間・年度・exact宣言打牌番号の
すべてで整数値が一致した。

## 主要結果

- パターンあり: 1,023,879件（9.562962%）
- パターンなし: 9,682,835件
- Aのみ: 889,468件
- Bのみ: 119,537件
- AとBの両方: 14,874件

| 指標 | パターンあり | パターンなし | 差 |
|---|---:|---:|---:|
| 筋待ちを含む | 67.017489% | 60.991931% | +6.025559pt |
| 自己所有を除いて5枚以上の好形 | 67.575954% | 61.661538% | +5.914416pt |
| 両面を含む | 66.056048% | 59.157478% | +6.898569pt |

2020～2025年だけでも、筋待ち差は+6.044846pt、好形差は+5.928132pt、
両面差は+6.950608ptだった。

宣言打牌番号別では、2～17打目の各区分で筋待ち率・好形率の差はいずれも正だった。
18打目以降は件数が小さいため、符号を含めて安定した傾向とは解釈しない。

## 人工テストと不変条件

次を含む人工テストを実施した。

- A、B、非該当、AとBの両方
- ツモ切り→手出し→手出しの重複ペアと排他的record分類
- 宣言牌を2枚目とする距離0
- 赤5の正規化、字牌、非連続打牌、2枚目ツモ切り
- call metadataが主分類へ影響しないこと
- 4分類、パターン有無、ペア数分布、距離分布の合計不変条件
- 年度・exact宣言打牌番号の合計とoverallの一致
- serial/parallelの内容・順序一致
- worker failure、malformed JSON、行数不一致のfail-closed

実装時の全pytestは897件PASSした。Ruff check、Ruff format check、`git diff --check`も
PASSした。

## 実牌譜監査

集計器がstable keyで決定論的に選んだ20件について、元MJAIをread-onlyで再読込した。
各sampleの`start_kyoku_line`と`reach_line`を物理行へ対応させ、対象actorの宣言打牌までの
全`dahai`から、該当ペア、A/B分類、最後に完了した代表ペア、宣言までの距離を再計算した。

- 監査件数: 20
- 分類・該当ペア・代表距離の一致: 20/20
- 不一致: 0
- 監査カテゴリ未発見: 0

監査は少数の原本照合であり、全件の正しさを証明するものではない。全件集計ではDTO検証、
入力hash、partition invariant、既存baselineとの整数値照合を別途実施している。

## 解釈上の限定

全期間の単純差には宣言打牌番号などの構成差が含まれる。exact宣言打牌番号別でも差が残る
ことは確認したが、これは因果効果、追っかけリーチやベタ降りの最適解、実際の放銃率を示す
ものではない。また、筋待ちを含む率が高いことは、個別の筋牌が必ず安全であることを意味
しない。
