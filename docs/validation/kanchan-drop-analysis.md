## 解釈上の限定

この分類は河の外形であり、実際の手牌に嵌張ターツがあったことや打牌意図を
証明しない。A/Bはともに14枚から最弱ブロックを処理した選択として主群へ含めた。
宣言打牌番号別、年度別、対子落とし型なしでも確認するが、因果効果や押し引きの
最適解は示さない。筋待ち率は個別の筋牌の安全性、好形率は実際の山残枚数を
意味しない。
