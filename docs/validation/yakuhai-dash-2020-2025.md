# 役牌ダッシュ分析・2020〜2025年全件実行後の研究監査

監査日: 2026-09-24
対象: `outputs/yakuhai-dash/summary-v2.json`（schema version 2、全件実行）
再現コマンド: `.venv\Scripts\python.exe analysis\audit_yakuhai_dash.py --input outputs\yakuhai-dash\summary-v2.json`

## 結論

対象範囲の原本照合で不一致は見つからなかった。これは標本監査の結果であり、
全1,105,844対象牌譜の全イベントを別実装で再集計したことを意味しない。
局収支・和了率に対する「役牌ダッシュの優位性」も、この監査からは判断しない。

## 入力と集計整合

- `.mjson` は1,105,845ファイルを走査し、うち1,105,844件が対象。
  除外された1件は2025年のrule code `00e1`であり、対象の`00a9`ではない。
- 東場6,374,545局、actor配牌25,498,180件（局数の4倍）、配牌孤立役牌
  34,948,620観測。
- 年度別の局・配牌・役牌対子・strict dashの件数を合算すると全体値に一致。
  先着5区分、本人結果3区分、親子・共有/自家専用の各区分も対応する全体観測数へ一致。
- 配牌役牌対子以上は5,165,483/25,498,180件（20.258%）。独立した
  組合せ基準の20.262%と近く、配牌集計の概算妥当性を補助的に確認した。
  strict dashは5,082,943/20,619,520対象配牌（24.651%）。

## 原本照合

`analysis/audit_yakuhai_dash.py`は本分析の判定関数・MJAIローダを使わずに
原本を読み、配牌枚数、役牌区分、自摸・打牌・副露・成立リーチの時系列、
ソース行番号、先着区分、打牌後の同牌自摸と他家対子化を再構成する。
配牌向聴数も、本分析の色別形状合成とは別の手牌全体DFSで再計算する。

## 残る限界

- 標本照合で不一致0は、未抽出の全局について誤り0を保証しない。
- 年別監査標本は先頭から決定論的に取られるため、別選定を加えたが、
  144牌譜も無作為抽出ではない。
- `opponent_pon_capable`は対子保有と成立リーチの有無を見た近似で、
  すべての鳴き制約や鳴く意思を判定したものではない。
- 実行モデルと推論強度は本タスクから確認できず「未確認」。
  `AGENTS.md`指定の`Astra / xhigh`で実施したと推測・表示しない。
