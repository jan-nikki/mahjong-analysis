# 国士無双テンパイで成立した立直：2009〜2025年DB全件抽出

DB内の保存済み対象牌譜 2,465,361 半荘・26,326,644 局を走査した。
成立立直 17,857,520 件のうち、国士無双テンパイでの成立立直は 604 件。
通常の1種待ち 583 件、13面待ち 21 件。
該当する局は 604 局、対局は 604 半荘。通常立直 597 件、ダブル立直 7 件。

## 対象と定義

- 入力：`data/archives/v1.2.0-db/2009.db`〜`2025.db`。DBは読み取り専用で接続。
- 四人打ち・半荘。`game_type` 列があるDBは `houou` のみ。東場・南場・延長局を含む全局。
- 1成立立直につき1レコード。`step=2` を成立根拠とし、宣言牌を除いた13枚で判定。宣言牌ロン等の未成立宣言を除く。
- `who` と `kyoku_index` は0始まり。`turn` は宣言牌を含む本人の打牌数で1始まり。
- 待ち牌の `m/p/s` は萬子・筒子・索子、`E/S/W/N/P/F/C` は東・南・西・北・白・發・中。
- 対象メタデータは 2,465,373 行、本文欠損は 12 行。全件とは保存されている対象本文の全件を指す。
- 2025年DBの実収録期間は 2025-01-01T00:01〜2025-10-16T11:32。2025年末までの完全収録ではない。
- 2009年DBの最初の対象牌譜は 2009-02-01T03:18。各年度の収録先頭・終端は検算JSONに記録した。
- `is_processed` / `was_error` の変換フラグでは除外せず、利用可能な本文を解析した。

## 検証

- pytest：全 890 テスト成功。追加ファイルのRuffチェック成功。
- 先行サンプル：各年のlog ID順先頭1,000、計17,000半荘・182,199局・成立立直122,814件・国士立直3件。独立照合の差分0。
- 全件独立照合：2,465,361 半荘。年別主要カウンター、候補キー集合、全10出力フィールドの差分0。
- 独立側は本番の牌種定数、meld decoder、手牌再生、待ち判定をimportせず、別経路でXML状態タグを読み、固定面子なしの手牌を集合で復元して么九牌の枚数を直接判定。
- 独立側の逐次再生と、成立したactorの履歴だけを再生する高速経路は、実牌譜1,706件（各年100件と既知の特殊例）でも全出力・復元手牌・件数が完全一致。
- 全検出例の宣言後13枚の物理牌ID・牌種・XML内の成立タグbyte offsetを検算JSONへ保存。
- 2009年の全3検出例は既存MJAI原本と既存再生処理でも13枚と巡目の一致を確認。サンプル3件が全件結果に含まれることも確認。
- 人工ケース：13面待ち、通常待ち全156組合せ、宣言牌による待ち変化、ツモ切り表記、暗槓、複数人の立直、ダブル立直中断、未成立、異常な成立列、並列・逐次一致。検算に候補欠落や待ち・巡目変更を故障注入して差分検出を確認。

## 実DBの形式差と扱い

- 同値の結果属性重複を正規化した牌譜：13 件。`AGARI/RYUUKYOKU` 上の完全同値重複だけを受け入れる。異値重複や状態タグの重複はエラー。例：`2010051013gm-00a9-0000-607b52e9` の重複 `owari`。
- 宣言打牌が `step=1` の直前に記録された成立立直：2 件。同じactorの直前打牌と打牌後枚数を確認。例：`2018031523gm-00a9-0000-77f4acb0`。
- `2022010616gm-00a9-0000-d4d83e3e` では、副露済みactorの加槓牌88が直前に打牌としても記録されていた。副露後は国士・立直とも不可能なため、そのactorの以後の物理牌増減を追わず、鳴きの発生と他家の手牌を追跡する。牌譜・局の除外はしていない。
- 本機能は対象となる立直手牌を検証する検索であり、副露済み手牌を含む全アクションの合法性検証ではない。
