# 立直宣言牌別の待ち強度：検証記録

## 結論

2020〜2025年の鳳凰卓東南戦・東場・赤ありの成立リーチ4,936,197件を、
辺張を含む修正版の定義で全件再集計した。強形は3,072,674件
（62.247799%）、弱形は1,863,380件（37.749304%）、その他は143件
（0.002897%）だった。

旧版でその他に入っていた純粋な辺張4枚待ち等227,934件が弱形へ移った。
強形は件数・率とも変わらず、残るその他143件はすべて国士単騎だった。
国士十三面2件は形式待ち枚数39枚のため強形だった。

同じ全件走査で、ドラ優先分類後の非ドラ数牌4,100,229件を宣言牌の実rank
1〜9へ分解した。さらに、宣言rankと同色で数字差3または6の待ちrankを含む
18組を、1recordが2組へ入ることを許す非排他的表として保存した。

## 定義

ドラ切りを最優先する排他的分類とし、残りを19・28・37・46・5・字牌へ分けた。
この版のドラは赤5または局開始時の表ドラで、槓ドラは含めない。

強形を先に判定し、次のいずれかを満たすrecordとした。

- 両面を含む。
- ノベタン等を含む既存の`contains_suji`を満たす。
- 自己所有分を除いた重複なしの形式待ち枚数が5枚以上。

弱形は、強形ではなく、形式待ち枚数が4枚以下で、全待ち解釈が
単騎・嵌張・辺張・双碰のいずれかであるrecordとした。その他と合わせた3区分は
排他的で、すべての集計階層で全recordを分割する。

## exact打牌番号

帯域内の全recordのexact打牌番号分布を共通重みとして標準化すると、旧版で
報告した次の4差を再現した。

- 4〜9打目: 19切りが5切りより2.29699pt高い（約2.30pt）。
- 10〜15打目: 5切りが19切りより0.93884pt高い（約0.94pt）。
- 1〜3打目: ドラ切りが字牌切りより3.84221pt高い（約3.84pt）。
- 7〜9打目: 字牌切りがドラ切りより4.29106pt高い（約4.29pt）。

辺張変更は強形へ影響せず、差の変化はなかった。単純なカテゴリ内プール率では
なく共通打牌番号分布による標準化差である点を、記事とWork資料に明記した。

## 宣言牌と同じ筋列に待ち牌を含む

宣言牌と同色で数字差3または6の形式待ち牌を含むrecordは全体で312,130件
（6.323289%）。うち弱形は207,615件で、次の4つの分母を区別する。

- 全リーチ中の`weak_and_same_suji_line`: 4.205971%（207,615 / 4,936,197）。
- 弱形内で該当する率: 11.141850%（207,615 / 1,863,380）。
- 該当record内の弱形率: 66.515554%（207,615 / 312,130）。
- 該当recordを除外した母集団の弱形率: 35.807548%
  （1,655,765 / 4,624,067）。

## 再現性と検証

- 入力manifest SHA256:
  `2bbe3409fb8d8ba4e5c34f7531592e3f7e0a1685215f2617f91e27cbdbaa7127`。
- canonical annual fileのsize/SHA256、DTO、年度件数、合計件数を検証した。
- 全record、年度、年度×exact打牌番号の既存待ち品質が
  `riichi-wait-quality-v1.json`と完全一致した。
- 全体・年度・exact打牌番号・宣言牌分類で
  `strong + weak + other = record_count`を検証した。
- 非ドラ数牌rank主表と18組を全体・年度・exact打牌番号へ保存し、全142 sliceで
  rank/category再構成、pair強弱その他分割、待ち枚数分布合計を独立検査した。
- 年度合計、打牌番号合計、7宣言牌分類合計が上位sliceと完全一致した。
- `weak_and_same_suji_line + weak_and_not_same_suji_line = weak_wait`を全sliceで
  検証した。
- 人工完成手牌で純辺張、純嵌張、辺張を含む5枚以上、国士単騎、国士十三面を
  検証し、強形条件の優先も確認した。
- 2年度fixtureに加え、4,936,197件の全件でもworkers=1とworkers=6の結果を
  完全一致比較した。serial全件走査は1,782.7秒だった。
- 各分類の先頭例を原MJAIから再確認し、`start_kyoku`、`reach`、宣言`dahai`、
  `reach_accepted`が7/7件一致した。
- 最終schema 3のworkers=6全件実行時間は660.9秒（manifestと全17年分入力SHA256検証を
  含む）。結果JSONのSHA256は
  `e141b0c058b75634d5a02e351c052557146c2fe9c36c222eb352774b7c941e25`。
- schema 2の直前結果SHA256
  `c00135c529234839a0d89a436c381e3508b8112f0de042612fa5000548d9cadf`と比較し、
  全体・年度・exact打牌番号・7分類のstrong/weak/otherが完全一致した。

## 記事で修正する点

- 旧版の弱形率33.13%とその他率4.62%を使わず、37.7493%と0.0029%へ置き換える。
- 純辺張4枚待ちは弱形と説明し、残るその他は国士単騎143件とする。
- 強形率と打牌番号別の強形に関する結論は変更しない。
- 46・5切りの弱形率が高い点には筋列該当recordとの関連を追記する。
- 非ドラ数牌の実rank 1〜9と18組を用い、4〜6切りでの集中と、3→9・7→1との
  対照を追記する。rank主表は排他的、pair表は非排他的と明記する。
- 記事用語は原則「宣言牌と同じ筋列に待ち牌を含む」とし、一律に
  「筋ひっかけ」と呼ばない。

## 限界

- 槓ドラはドラ切りへ再分類されず、通常の牌種群に残る。
- 形式待ち枚数は本人の手牌だけを控除し、河・他家・実山残りを控除しない。
- 和了率や放銃率を分析したものではない。
- 成立リーチだけが対象で、未成立宣言やダマ手は含まない。
- 宣言牌は手牌構成・テンパイ過程の結果でもあり、因果関係、打ち手の意図、
  個別局面の最適打や個別牌の安全度を示さない。
