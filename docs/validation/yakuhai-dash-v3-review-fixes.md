# 役牌ダッシュ v3 レビュー指摘修正の検証

実施日: 2026-09-24

## 変更と範囲

- 保存標本の年・区分・必須フィールド・母集団件数・件数・重複を検査する。
  空の検査集合や標本保存無効の出力を合格にしない。母集団0件の区分は標本0件を許す。
- 開始打牌区分の原本照合でも、配牌孤立役牌を1種類以上持つ母集団条件を確認する。
- 別選定監査は対象rule codeのファイルから選び、各年の対象牌譜・東場局が0件なら不合格にする。
- `self_pair_draw`を維持し、その後の最初の自打直後に対子を保持したか、
  リーチ宣言・成立による鳴き制約がないかを追加する。実ポン機会の完全判定ではない。
- `--progress`で実行中の開始・途中・完了を表示し、`--checkpoint-dir`で完了年を保存する。
  年別保存ファイルからの自動再開は含まない。
- 出力はschema version 3、全件既定名は`summary-v3.json`。v2の既存結果は維持する。

## 検証結果

- 全体pytest: 1,513件通過。その後の監査母集団条件修正と2件の回帰テスト追加後、
  監査テスト21件が通過。全体テストのうち19件が監査テストなので、確認済みの固有テストは計1,515件。
- 実装担当の個別テスト: 判定30件、CLI10件が通過（上記全体テストにも含まれる）。
- 2020〜2025年の各年先頭100牌譜、計600対象牌譜を3workerで実行し、
  東場3,440局、配牌13,760件、孤立役牌18,849観測を集計。6年分の年別保存ファイルも確認。
- v3保存標本339件（59原本、重複除去後220観測）を独立再構成し、不一致0件。
  年別件数は2020年から順に56・55・57・57・57・57件。
  全19区分×各年上限3件との差は母集団が3件未満の区分によるもので、保存漏れではない。
- 別選定144対象牌譜・東場845局・配牌3,380件・孤立役牌4,603観測も不一致0件。
  対象rule codeの候補から選ぶよう変更したため、旧監査の852局とは選定集合が異なる。
- 既存v2全件結果の保存標本306件を修正後の監査器で再検査し、不一致0件。
  v2に保存されていない設定標本上限は推測せず、母集団あり区分の空標本等を検査する。
- 既存`summary-v2-sample-21.json`と同じ2025年先頭21牌譜を再集計し、新指標を除く
  全体・年度別集計と入力件数がすべて完全一致。

600牌譜サンプルの対子化1,874件の内訳:

| 最初の後続自打の結果 | 件数 |
| --- | ---: |
| 対子保持・リーチ制約なし | 1,817 |
| 対子非保持 | 37 |
| 対子保持・リーチ制約あり | 12 |
| 後続本人打牌なし | 8 |

対子保持は1,829件（1,817+12）。これは各年先頭100牌譜の検証用標本の数値であり、
2020〜2025年全件の推定値として扱わない。

レビューで挙げた即時対子ほぐしの原本
`2020/2020110917gm-00a9-0000-6cdad3ba.mjson`（開始120行、actor 0）は、
209行の東自摸を従来どおり対子化として記録し、210行の東切り後の保持・ポン可能形を
ともにfalseとすることを確認した。行番号は展開後MJAIに対応する。

## 再現コマンドと成果物

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m pytest -q tests/test_audit_yakuhai_dash.py
.venv\Scripts\python.exe analysis\analyze_yakuhai_dash.py --max-logs-per-year 100 --workers 3 --progress --output outputs\yakuhai-dash\review-fixes-v3-sample-100.json --checkpoint-dir outputs\yakuhai-dash\review-fixes-v3-sample-100-years
.venv\Scripts\python.exe analysis\audit_yakuhai_dash.py --input outputs\yakuhai-dash\review-fixes-v3-sample-100.json
.venv\Scripts\python.exe analysis\audit_yakuhai_dash.py --input outputs\yakuhai-dash\summary-v2.json
```

サンプル集計の再実行時は、出力・年別保存先ともに未使用のパスを指定する。
監査コマンドは既存結果を読み取るだけなので再実行できる。
