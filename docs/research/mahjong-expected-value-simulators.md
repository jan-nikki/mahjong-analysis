## 1. nisiシミュレータ

作者の[「機能編」](https://note.com/mahjong_math/n/n79ad61ff9f01)（2020-04-07）は、戦術の根拠となる数値を得るために使い、旧・新の2種類があると説明する。

追加調査で、作者ブログの[無料のアルゴリズム概要](http://epsilon69399.blog20.fc2.com/blog-entry-478.html)（2015-09-27）と[旧版の配布記事](http://epsilon69399.blog20.fc2.com/blog-entry-457.html)（2015-08-22）を確認した。旧版はツモ・ロンを区別し、ドラ待ちの出にくさ、放銃・被ツモ・横移動、最終順位なども扱う。シャンテン計算等の関連ソースは公開されているが、本体の全ソースの公開先は今回未確認。詳しくは[nisiの予備調査メモ](nisi-simulator-evidence.md)を参照する。

新nisiシミュレータについて、公開部分だけでも次を確認できる。

- [牌の危険度の算出法](https://note.com/mahjong_math/n/nda34d2465314)（2020-05-12）：自分が切った牌が他家にロンされる確率を計算する。
- [他家アガリ時打点の決定方法](https://note.com/mahjong_math/n/nd4730d8f9694)（2020-12-11）：他家が和了したときの翻数・符数を決める。過去の打点見積もりの問題を改修した経緯も書かれる。これは当時の変更履歴で、現行版の欠陥と断定する根拠にはしない。
- [仕組み編](https://note.com/mahjong_math/n/nfc5cb2df6a30)（2020-04-14）：アルゴリズムと誤差評価を説明する章がある。確認した無料部分はモンテカルロシミュレーションの節見出しまでで、詳しい処理は読めていない。

新nisiシミュレータを「ロンも他家もない一人麻雀」と分類してはいけない。ただし、具体的な計算方法や現行版の精度まで確認したわけではない。

出版社の[『麻雀 激ムズ何切る問題集』紹介](https://tetsujinsya.co.jp/5620/)（2023年刊）は、nisi氏独自のシミュレータによる解答に、堀内正人氏とNAGAの解答を併記すると説明する。後続の麻雀AIの記事との関連資料になる。紹介文の「正解」等は出版社の宣伝表現で、精度の検証結果として採用しない。

関連して、[『新 科学する麻雀』の出版社掲載の調査報告](https://hobbyjapan.co.jp/mahjong/explanation.html)（2021-10-29）は、同じ先制リーチという名称でも他家の副露を条件に含むかで比較対象が変わり、リーチ棒や赤受けの扱いも数値差に関係すると説明する。一部は追試に基づく推測と明記される。記事では「計算条件を揃えて比較する」例として扱えるが、報告の結論全体を独立に再検証したわけではない。

## 2. あら氏の一人麻雀練習機

[作者のルール・計算説明](https://mahjong.ara.black/sim/rule.htm)では、牌効率の練習と一定のアルゴリズムでコンピュータに一人麻雀を打たせる機能を持つWindows用フリーソフトとされる。[Vectorの作者登録情報](https://www.vector.co.jp/soft/win95/game/se254989.html)も確認した。

記事では、期待値計算や一人麻雀研究の従来のツールとして紹介する。作者のルール説明はシミュレーションに用いたversion 1.31についての説明であり、全バージョンの機能一覧や現在のOS対応を示すものとは扱わない。

## 3. Critter氏・pystyle・tomohxx氏の関係

tomohxx氏の[ツール紹介](https://note.com/tomohxx/n/nea28d1c92ab3)（2026-08-12）は、あら氏・Critter氏・nekobean氏のツールを先行・類似例として挙げる。同記事で本人は、pystyleの期待値計算アルゴリズムと実装の大部分を自身が開発したと述べ、基礎となる方法はCritter氏のものと説明する。これは作者本人による開発経緯の説明として引用する。

- tomohxx氏のWebアプリ：[牌理・牌効率計算ツール](https://tomohxx.github.io/pairi/)。
- 計算方法：[一人麻雀期待値計算方法（概要編）](https://note.com/tomohxx/n/n971c88540721)。無作為の対局を大量に試行する方法ではなく、状態の値を終了巡目から逆向きに計算する方法と説明される。
- pystyleの調査：[既存の根拠メモ](pystyle-nanikiru-simulator-evidence.md)。

アプリ名に「シミュレーター」が含まれても、計算方式が必ずモンテカルロ法とは限らない。pystyleとtomohxx氏のツールには方法・開発経緯のつながりがあるため、両者の数値一致を独立した手法による検証と無条件に扱わない。

## 4. hata hirotaka氏の局収支シミュレーター

[作者の案内](https://note.com/bold_myrtle4902/n/n0b2325fbefb2)（2026-03-06）によると、2024〜2025年の天鳳鳳凰卓約40万半荘から、聴牌後のツモ率・ロン率などを集計して利用し、放銃やツモられのリスクも統計で反映する。リーチ・ダマの比較にも対応すると説明する。

同案内は、将来の新たな副露、他家の個別状況、一発・海底・河底、本場・供託などについて制約を明記し、当時の利用対象も限定している。これは作者による仕様説明で、元データの品質・条件別の集計・内部アルゴリズムを当方が監査した結果ではない。利用条件の現在の状態も未確認。

「期待値計算ツールはすべてツモしか見ない」という主張に対する、具体的な比較候補になる。

## 記事の方針（ユーザー了承済み）

**期待値の意味 → 一人麻雀で計算する範囲 → 他家を組み込む方法 → 麻雀AIの学習と判断**。pystyleとnisiを主な比較対象とする。

具体的な構成候補：

1. 期待値は何を平均した数値か（和了点、局収支、最終順位の区別）。
2. 一人麻雀で計算できることと、ロン・他家・放銃を除く影響。
3. 七対子のドラ単騎／西単騎、平和ドラ2／一通の高安の具体例。
4. 他家を統計や行動モデルで取り入れる方法。nisi等の扱う範囲を確認する。
5. 計算方式の違い（確率の漸化式、対局試行、学習済みモデル）。
6. 仮定・探索範囲・データの条件を確認して数字を読む。
7. 次の記事へ：人間の打牌を学ぶ教師あり学習と、対局結果から改善する強化学習。

未完了：新nisiシミュレータの現行仕様と一般配布状況、Critter氏の一次資料の取得、局収支シミュレーターの実装確認、各ツールの同一条件での比較、Xの実際の引用例の調査。候補一覧だけから精度や強さの順位は決めない。
