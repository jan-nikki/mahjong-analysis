# mahjong-analysis

天鳳牌譜を用いて、麻雀の「実際どうなの？」をデータで検証するプロジェクトです。

AIコーディングエージェントとPythonを使って分析コードを開発し、
人工テスト・実牌譜確認・独立実装との比較などを行いながら結果を検証しています。

## 現在の分析

### 親ダブルリーチの和了率

天鳳鳳凰卓の2009〜2025年を対象に、
東場で成立した親ダブルリーチを集計しました。

- 走査牌譜: 2,500,236半荘
- 対象対局: 2,500,235半荘
- 東場: 14,434,809局
- 親ダブルリーチ: 9,398局
- 親和了: 6,607局
- 親和了率: 70.30%
- 95% Wilson信頼区間: 69.37%〜71.22%

2009〜2025の年度差についてPearsonのカイ二乗検定を行った結果、
今回のデータでは年度による和了率の差を示す統計的証拠は検出されませんでした。

## データ

分析には以下のデータセットを使用しています。

- NikkeTryHard/tenhou-to-mjai
- release: v2.0.0
- 対象期間: 2009〜2025
- 四人打ち鳳凰卓・半荘・赤あり
- 分析対象局: 東場のみ

raw牌譜データや巨大な中間ファイルは、このリポジトリには含めていません。

## 検証方針

データ分析では「コードが動くこと」と「結果が正しいこと」を分けて考えています。

主に以下の方法で検証しています。

- 仕様を実装前に文書化
- 人工MJAIイベントによるpytest
- 実牌譜のpositive / negativeケース確認
- 本番実装とは別のreference実装との比較
- 件数だけでなく候補局・metadata・局結果まで比較
- 最古年2009と最新年2025で独立検証
- 既知結果による回帰確認
- 確定した集計結果をGitで保存
